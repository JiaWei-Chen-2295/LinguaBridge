## 当前 MVP 决策摘要

- Windows 10/11 PC 首发。
- 系统音频录制，不以浏览器扩展作为主路径。
- 英文 -> 简体中文优先，预留多语种。
- 先做实时字幕与字幕纠错，不首发语音同传。
- 音频、原文、译文、修订历史落盘，默认保留 30 天。
- Alpha 阶段使用邀请码 + 用量统计，不先接正式支付。
- 模型与云服务优先使用阿里云。
