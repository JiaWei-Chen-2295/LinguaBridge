# LinguaBridge

言桥（LinguaBridge）— 跨语言沟通桥梁。

## 简介

LinguaBridge 当前聚焦于面向中文技术学习者的 PC 端 AI 实时字幕与翻译伴学工具。

MVP 目标是在 Windows 10/11 上通过系统音频录制生成英文原文与中文字幕，支持字幕自动纠错，并将音频、文本和修订历史落盘，供后续精读解析与学习复盘使用。
